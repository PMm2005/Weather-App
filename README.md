# Weather App

A modern and stylish weather app that fetches real-time weather data and a 5-day forecast using the WeatherAPI.

## Features
- Fetch real-time weather data by city name.
- Display temperature, weather condition, humidity, wind speed, and feels-like temperature.
- Show a 5-day weather forecast.
- Dynamic background and responsive design.
- Loading spinner for better user experience.

## Technologies Used
- HTML
- CSS
- JavaScript (Fetch API, async/await)

## How to Use
1. Clone the repository.
2. Open `index.html` in your browser.
3. Enter a city name and click "Get Weather".
