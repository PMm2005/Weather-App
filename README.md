# Weather App

Weather App
🌦️ A modern and stylish Weather App that provides real-time weather data and a 5-day forecast for any city worldwide. Built with simplicity and user experience in mind, this app is perfect for showcasing your skills in API integration, asynchronous JavaScript, and responsive design.

Features
Real-Time Weather Data:

Get current weather conditions, including temperature, humidity, wind speed, and "feels-like" temperature.

Displays weather icons for a visual representation of conditions.

5-Day Weather Forecast:

View a detailed 5-day forecast with maximum and minimum temperatures.

Dynamic Background:

A sleek gradient background enhances the visual appeal of the app.

Responsive Design:

Works seamlessly on all devices (mobile, tablet, and desktop).

Loading Spinner:

A smooth loading animation ensures a great user experience while fetching data.

Error Handling:

Gracefully handles errors, such as invalid city names or API issues.

Technologies Used
Frontend:

HTML5, CSS3 (Flexbox, Grid, and animations)

JavaScript (ES6+ features like async/await and Fetch API)

API:

WeatherAPI for real-time weather data and forecasts.

Design:

Modern and clean UI with a focus on user experience.

Responsive layout for all screen sizes.
